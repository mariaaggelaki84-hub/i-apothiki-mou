Η ΑΠΟΘΗΚΗ ΜΟΥ — ΟΔΗΓΙΕΣ ΕΓΚΑΤΑΣΤΑΣΗΣ

Τι περιλαμβάνει
- index.html: η οθόνη της εφαρμογής
- app.js: καταχώριση, αναζήτηση, διόρθωση, διαγραφή και αντίγραφα ασφαλείας
- manifest.webmanifest: στοιχεία εγκατάστασης ως εφαρμογή
- service-worker.js: αποθήκευση αρχείων για χρήση χωρίς ίντερνετ
- εικονίδια εφαρμογής

ΣΗΜΑΝΤΙΚΟ
Αυτό είναι πακέτο εφαρμογής ιστού (PWA), όχι APK. Για να εγκατασταθεί σαν κανονική εφαρμογή με εικονίδιο και να λειτουργεί offline, πρέπει πρώτα να δημοσιευτεί σε ασφαλή διεύθυνση HTTPS. Το άνοιγμα του index.html απευθείας από το ZIP/τα Αρχεία δεν ενεργοποιεί την εγκατάσταση PWA ή την offline cache.

Εγκατάσταση στο Samsung (μία φορά με ίντερνετ)
1. Δημοσίευσε ΟΛΑ τα αρχεία αυτού του φακέλου σε μια δική σου HTTPS φιλοξενία στατικών αρχείων (π.χ. GitHub Pages). Μην αλλάξεις τα ονόματα των αρχείων.
2. Στο Samsung άνοιξε τη δημοσιευμένη διεύθυνση με Chrome.
3. Περίμενε να φορτώσει πλήρως με ενεργό ίντερνετ. Αν εμφανιστεί, πάτησε «Εγκατάσταση εφαρμογής» ή μενού ⋮ > «Προσθήκη στην αρχική οθόνη» (η διατύπωση διαφέρει ανά έκδοση).
4. Άνοιξε την εφαρμογή από το νέο εικονίδιο όσο υπάρχει ίντερνετ μία φορά ακόμη, ώστε να αποθηκευτούν τα αρχεία για offline χρήση.
5. Δοκίμασε να ενεργοποιήσεις λειτουργία πτήσης και άνοιξέ την από το εικονίδιο.

Χρήση
- Προϊόν, κωδικός και LOT είναι υποχρεωτικά.
- Η αναζήτηση ψάχνει μόνο στον κωδικό προϊόντος και στο LOT.
- Η «Διόρθωση» φορτώνει τα στοιχεία στη φόρμα.
- Η διαγραφή ζητά επιβεβαίωση.
- Από «Αντίγραφο ασφαλείας» κάνε συχνά εξαγωγή JSON και φύλαξέ το σε ασφαλές σημείο.

ΠΡΟΣΟΧΗ ΣΤΑ ΔΕΔΟΜΕΝΑ
Οι καταχωρίσεις αποθηκεύονται τοπικά στον browser/στην εγκατάσταση της εφαρμογής. Αν καθαρίσεις τα δεδομένα του Chrome, κάνεις εκκαθάριση αποθήκευσης ή αλλάξεις συσκευή, μπορεί να χαθούν. Κράτα αντίγραφα ασφαλείας. Η εφαρμογή δεν συγχρονίζει αυτόματα με άλλη συσκευή και δεν συνδέεται με το εταιρικό WMS.
